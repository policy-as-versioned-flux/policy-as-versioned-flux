### A. Lessons that live only here and that the minimal loop will need

   - The reference must sit in its own Namespace with no governed label, no tier and no version claim. Both generators write into the pod's own Namespace (`generator.Apply(variables.nsName, ...)`), so a NetworkPolicy in the caged Namespace cannot select a pod elsewhere.

   - The kyverno CLI must be proved to read Namespace labels (a Values `namespaces:` list), and its version must be compared with the declared engine, or the offline harness silently grades the wrong rung.
   Today this lives in `drift/five-facts.py` in each adopter and in this folder. The target deletes `five-facts.py`. After that this README is the only record.
