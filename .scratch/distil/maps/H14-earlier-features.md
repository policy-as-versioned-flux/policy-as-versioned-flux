## The twin spec: exactly what it was meant to add to the loop

Stated by the spec itself: "senses any dated signal... binds it to the components it touches, and propagates its consequences along typed causal edges. Every impact and every candidate response is priced in one £ currency... The output is a trade-off curve across an ensemble, not a verdict" (twin/spec.md:53-58). Destination: "recommends the cheapest proportionate response wherever it lives" (twin/map.md:19-22). Step by step:

## What the loop would lose if this area vanished

- **Markdown spec files only:** nothing runs on them. The loop would lose no behaviour, only the rationale.
