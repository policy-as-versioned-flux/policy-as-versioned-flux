`kind cluster 'driftwood' is not listed by kind get clusters` — the hub runner performs no direct

evidence in the citable run arrives instead as the adopters' signed five-fact samples, which on
run 21 are all in the FAIL column (4 scripts), not the PASS column. That is the recorded design

KinD cluster" as its substrate.
