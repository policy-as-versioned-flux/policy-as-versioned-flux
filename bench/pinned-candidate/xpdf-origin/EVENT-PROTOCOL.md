# Closed raw Xpdf origin protocol checkpoint

Implementation checkpoint for independent verifier author negotiation. Raw child records only; no actual run/plan/config/binary pins or actual terminal status. Exact reviewed profile/FD3 argument remains unchanged. The host observation envelope and private acquisition are separate. All JSONL is canonical UTF-8: lexically sorted keys, no spaces, integer numbers, one LF. Strings use ASCII JSON escaping; only fixed ASCII discriminator/reason/hash/hex strings appear. Every record <=65536 bytes; full FD3 <=67108864 bytes; <=1000000 event records; scalar array length <=4096; source character-code hex is bounded to 64 bytes per item. Unsupported larger decoder items hold rather than truncate.

Header (no seq): exact keys emitter_protocol_version(integer1), profile(string pdf-text-xpdf-origin/2), schema(string twin.pdf-output-origin-events/v1).

All event records have record and seq, consecutive seq0..event_count-1:

| record | Additional exact keys | Meaning |
|---|---|---|
| fragment_open | code_bytes:int, code_sha256:hex64, fragment:positive int, page:positive int | Original GString operand bytes; no raw PDF offsets. Unique monotonic fragment IDs, no nested string operands. |
| item | code_end:int, code_hex:lowercase even hex, code_start:int, fragment:int, input_scalars:list[int], item:positive int, scalars:list[int], taint:enum | One actual decoder callback before layout, remapped scalar result and actual source code slice. Unique monotonic item IDs. For ordinary fragment>0, exact adjacent source code intervals cover the operand and concatenated code_hex checks its hash. Taint none requires input_scalars==scalars. Taint values none,unicode-remap,actualtext,unmapped. Replacement-only fragment0 has empty code_hex and zero code offsets and requires actualtext taint; it never supports an eligible witness. Scalar integers are valid Unicode scalar values. |
| fragment_close | consumed_code_bytes:int, fragment:int | Exact completed operand; all code bytes and item relations accounted for. |
| emit | end:int, operation:enum, origin_item:int, origin_scalar:int, reason:enum, start:int, utf8_hex:lowercase even hex | One output scalar or fixed generated UTF-8 sequence; exact continuous stdout partition. operation decoded/generated/modified. decoded references one existing none-taint item scalar, exact UTF-8 bytes, reason source. generated uses origin_item=0/origin_scalar=0; reason spacing,linebreak,bidi,bom,pagebreak,unmapped. modified references actual existing item scalar; reason mirror,remap,actualtext,duplicate,unmapped. |
| barrier | at:int, reason:enum | Zero-width boundary before current emit, reason fragment,source-gap,scalar-order,duplicate. Verifier reconstructs required barriers from actual item/code/scalar relations; omission cannot bless adjacency. |
| omit | item:int, reason:string not-emitted-by-reading-order, scalar:int | Decoder scalar not emitted by reading-order selection, emitted once in footer preparation for every otherwise unaccounted scalar. Not a claim of a particular reason for geometric/filter removal. |

Footer (no seq): exact keys closed_fragment_count:int, emitted_stdout_bytes:int, emitted_stdout_sha256:hex64, event_count:int, event_prefix_bytes:int, event_prefix_sha256:hex64, intended_exit_code:int0, record:string footer. Prefix is exact header+event bytes including their LFs and excluding footer/LF. Stdout fields describe typed emitter accounting and must equal actual host-captured bytes, never intended terminal proof. No following records.

Strict eligibility: unchanged contiguous ordered scalars in one source fragment, no tainted byte, no crossed reconstructed barrier. Between separate decoded items require same fragment, previous last scalar/next first scalar, adjacent source-code intervals. Within one item require next scalar index exactly previous+1. Reused scalar output is modified duplicate. Nonidentity remapping/ActualText/mirror/bidi/generated spacing are ineligible; deletion/join/reorder gaps remain barriers. First/last witness endpoints must be UTF-8 scalar boundaries. Ordinary output remains unchanged; bookkeeping cannot repair source bytes.

A pure parser/map proves structural consistency only. No public header/footer/map/envelope issues actual authority. Actual wait/EOF/reap/cleanup, all three captured streams and plan/run/executable/parent/config identities are independently bound by the reviewed host envelope/private native store; post-footer death/nonzero/partial streams refuse. Current native observer still denies FD3 until a separate policy revision.
