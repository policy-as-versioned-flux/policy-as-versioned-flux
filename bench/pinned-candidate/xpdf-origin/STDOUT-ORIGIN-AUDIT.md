# Static origin and stdout coverage audit

Baseline: official Xpdf4.06, exact archive and member pins retained by the source
package. This is source inspection plus compilation/standalone recorder evidence;
none of the upstream converter/PDF paths has been executed. Every prospective
native row in the reviewed contract remains unrun.

| Upstream path | Authored propagation/control | Remaining actual proof |
|---|---|---|
| Gfx doShowText → TextOutputDev beginString/endString | Existing callbacks create unique page-local operand fragments; actual operand bytes are hashed and consumed as code slices. TJ strings/repeated forms remain distinct invocation identities. | Public PDF callback fixtures and actual native trace, including Type3 and malformed input. |
| TextPage addChar early ActualText/filter/bounds/tiny/whitespace returns | Actual input decoder item/code bytes recorded before omission. Whitespace isn't reclassified as publisher spacing. | Native filter/ActualText/whitespace cases. |
| Existing Unicode remapping | Input and mapped scalar arrays retained; nonidentity mapping is modified/ineligible. | Native remapping resources and edge cases. |
| ActualText replacement through endActualText | Separate fragment0 replacement items, always actualtext/ineligible; original covered glyph items remain distinct and omitted. | Native replacement, nested/invalid fragment handling. |
| TextChar → TextWord → TextWord copy → TextLine | Plain item/scalar references copied alongside the existing Unicode values. New line/word spaces have generated references. No string-search reassociation. | Native rotation/overlap/copy paths. |
| Duplicate suppression/removal/hyphen deletion | Unemitted decoder scalars retained as omit records; every output source discontinuity reconstructs a barrier. Repeated emission is modified/duplicate and barriers are conservative. | Native duplicate/line/column cases. |

| pdftotext version/list-encoding informational printf | Origin option requires the exact fixed argv shape before parse/info stdout dispatch. | File output callback | Typed byte relation recorded before the original callback; final stdout flush/ferror checked before raw footer. Host must still independently compare complete received streams. | Native stdout short-write/EOF/post-footer fatal wait/cleanup cases. |

The patch intentionally changes no layout/decoder/output ordering algorithm. It
adds origin bookkeeping, checks, the fixed origin option and required object
linkage. Allocation/record caps can hold an invocation; no successful equivalence
claim is inferred from compilation. An uncovered actual path remains held.

The standalone recorder demonstrates positive contiguous-fragment support as
well as source-gap, mirror/duplicate, remapping, ActualText, UTF8 and scalar-order
refusals. The source page-state revision additionally preserves the barrier before
an adjacent page2 fragment. These authored literal controls do not demonstrate
that Xpdf calls those paths correctly on an actual PDF.

Raw child header/footer contain only internally known protocol/emission facts.
Actual run/parent/config/executable/plan identity, complete three-stream capture,
actual wait/EOF/reap/cleanup and native dependency observations belong to the later
host envelope/private native store. No public map or envelope enrolls actual
metadata. The ordinary PDF profile's quotation hold remains unchanged.
