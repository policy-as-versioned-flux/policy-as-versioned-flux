# What each script in the gate measures (eco-system ticket 83). Read by talk/verify-all.sh
# through talk/truth_manifest.py, which documents the format; the short form:
#
#   path | class | skip        # a trailing comment is the place for a borderline note
#
#   class  estate-observation  the verdict turns on the CONTENT of another party's artefact or
#                              on live state outside the script's own repository
#          self-proof          a party grading its own code, fixtures or artefacts (using another
#                              party's schema or engine as the RULER is still self-proof)
#          simulation          synthetic or throwaway material, said so in the verdict
#          meta                grades other checks or the record, not the estate
#   skip   -                   no could-not-look expected; one that happens FAILS the gate
#          never: <regex>      cannot pass on the scheduled runner as built (no cluster, no
#                              cross-org credential); outside the CEILING
#          waits: <regex>      the estate's own state has not arrived; inside the ceiling
#          the regex is matched case-insensitively against the script's last line on exit 3;
#          it runs to the end of the line, so alternation with '|' is fine, and '#' cannot appear
#
# The judge sees the WHOLE last line. talk/verify-all.sh cuts it at 160 characters for the grade
# table only (fixed 2026-09-04: run 70 graded a correctly declared could-not-look FAIL because the
# runner's absolute path pushed the declared phrase past the cut). A pattern may therefore sit
# anywhere in the line.
#
# KNOWN LIMIT, ticket 83 decision 3. A pattern that matches an AGGREGATE could-not-look line
# ("3 of 9 checks could not be looked at") declares the shape of the sentence and not the reason
# for it, so a NEW underlying reason still hides under the old declaration. Four lines are in that
# state: insurer/verify-insurer-quote.sh, platform/verify-publisher-gate.sh,
# verify/e2e/verify-e2e-step6-provenance.sh and verify/feed-contract/verify-untagged-pin-is-priced.sh.
# Narrowing them needs each script to name its own reason on its last line, which is a change to
# four scripts in four repositories and is not this ticket's.
#
# Every script talk/verify-all.sh discovers must be here or in talk/verify-exclusions.txt; every
# line here must name a script that exists. The TRUTH line prints the split of passes by class,
# the split of skips by kind, and ceiling = total - excluded - never.
#
# THE SUBSTRATE THIS FILE IS DERIVED FROM (delegated, ADR-0025, 2026-09-04). Every row is
# derived from what the script prints ON THE SCHEDULED RUNNER: no cluster, no docker daemon
# worth the name, no cross-org credential. A machine with live KinD clusters is a DIFFERENT
# substrate, and six `never:` rows pass there instead of skipping, which the gate grades
# `FAIL manifest: ... passed but the manifest says it can never pass`. Those are artefacts of
# the substrate, not of the estate, and they are named in .scratch/ecosystem/REPAIR-2026-09-04.md.
# A runner qualifier that turns a stale-never judgement into a NOTE when the run is off the
# runner was considered and NOT built here: it changes what `ceiling` means, which is the one
# number NORTH-STAR publishes, so it is its own ticket, not a line in a repair.
# The kind rule that follows from this: when a script's could-not-look ON THE RUNNER is a
# missing substrate, its row is `never:`, and the pattern also names the reasons the same tail
# prints where the substrate IS there, so the row is true in both places and a new reason still
# cannot hide. When the runner's reason is the estate's own state, the row is `waits:`.
#
# The classification rule (delegated, ADR-0025, 2026-09-04): a pass is an observation of the
# estate only when its verdict turns on another party's artefact or live external state; a
# script whose live tail needs a cluster is classed by what its PASS would rest on, so the
# cluster tails are estate-observation with `never:`. A line for a script listed in
# talk/verify-exclusions.txt is kept and inert: it records what that script would have measured,
# so the day it re-enters the gate its class is already decided, not re-argued. The runner's
# substrate reason today is
# "kind cluster 'driftwood' is not listed by kind get clusters" (platform/lib.sh) or "does not
# exist" (tuppence). Ticket 86 (lane branch) edits the `never:` line it lifts;
# ticket 91 un-retired the currency controller and re-wrote its line (2026-09-05). Ticket 56 lifted its own
# (2026-09-04): the schedules credential is no longer the ceiling, the ruleset is.
